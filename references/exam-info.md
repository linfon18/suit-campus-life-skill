# 考试动态与报考信息核实

本文件提供官方查证流程、注明核验日期的 CET 笔试结构摘要，以及单独注明来源的本校报名补充，不是当期报名政策库。原包中的 2026 年日期、固定费用、2027 年预测和未经核实的在校生资格不再作为官方结论依据；用户补充只作条件性参考，没有核实就保留未知。

来源：用户于 **2026-11-14** 补充；尚未取得可核实这条条件的本校正式通知，适用入学年级 / 考次未明确。下面是用户提供的校内条件，不是已核实的校方公告或全国统一规定。

| 事项 | 用户补充的条件 |
|---|---|
| 适用学校 | 深圳信息职业技术大学 |

遇到“深信大专科大一能不能报四级、最快什么时候报、期末 79 / 80 分能否报”等相近意图，读取本节并结合已知学期、学生层次与成绩作条件性判断，答复明确说“按你补充的校内条件”。已有信息不要重问；两项均满足时只能说符合本节列出的条件，报名资格录入、名额、窗口及其他条件仍以当期学校正式通知为准，不承诺能报名成功。

“大一上期末成绩”的具体课程和统计口径未明确，不能自行改成英语单科、总平均分、绩点或补考后成绩；该口径会影响个案判断时，只追问必要信息或查校方原文。低于 80 分表示不满足本条所述的大一下报名条件，不能推出以后一直不能报；不把本条扩展到本科生、高年级学生、六级或其他学校，也不推断本科生规则相同。

本校当前考次的资格查询优先用环境网页 / HTTP 工具读取主站通知公告 `https://www.suit-sz.edu.cn/index/tzgg.htm`，从真实链接核实相关正文；没有可用工具或读取受阻时，保留内置 `official_fetch.py --exam school` 保底。只覆盖主站公开通知，不接入教务内网；主站未检出不代表学校没有发布，旧公告标题提到四六级也不能证明仍适用。全国 CET 笔试介绍和“考试动态”不能证明本校存在这条 80 分门槛；若官方通知与本条冲突，说明适用对象、考次或条文差异，按当期适用的正式通知作结论。

仅引用本条而未联网时，依据写“用户补充的校内报名条件，未独立核实”，本次网络来源写“本次未获取网络 URL”；不为本条编造学校公告链接或套用下文 CET 官方来源。最后快速预览仍标明资格依据及待核实项。

## CET 笔试：题型、题量与分值比例

官方来源：[CET笔试（中国教育考试网）](https://cet.neea.edu.cn/html1/folder/16113/1586-1.htm)。以下为 **2026-11-14** 实际读取并核对的英语四级、六级笔试结构摘要，适用于“笔试考什么、听力占多少、题型区别、考试做多久”等问题及相关备考计划，不适用于 CET-SET 口语或其他语种考试。

普通结构问答可直接使用本节并注明核验日期，不必先搜 GitHub 或下载试卷。用户要求最新、特定考次、改革后结构，或有资料冲突时，先用环境网页 / HTTP 工具重读上述原页；工具缺失或读取失败时，用随包脚本按原址保底：

```text
python -I -S -X utf8 "<技能目录>/scripts/official_fetch.py" --exam cet --url "https://cet.neea.edu.cn/html1/folder/16113/1586-1.htm"
```

刷新失败则说明未核实最新变化，只能把下表作为此前核验的结构参考，不称为本轮实时确认。该笔试页面与“考试动态”新闻栏目用途不同，不为查题型自动扫描新闻、餐饮或题库。

## 四六级官方新闻入口

“四六级最近新闻 / 消息 / 公告”“四级报名通知”“六级查分安排”等表达按语义进入本流程。首选中国教育考试网四六级“考试动态”栏目：`https://cet.neea.edu.cn/html1/category/16093/1124-1.htm`，具体地址也登记在 [official-sources.json](official-sources.json)。先读栏目，再跟随本次列表实际出现的相关公告链接读正文；不用 GitHub 学习资料、校园新闻栏目或搜索摘要替代官方考务消息。

默认“最近”看近 30 天发布的公告；用户给定时间则依其范围。没有新公告是有效结果，不触发保底或重抓；可补充列表中最近一条相关公告，但必须标出实际发布日期和超出所查时间范围。列表发布日期不等于报名截止或考试日，正文仍须核实；截断、分页未读完或正文失败时披露覆盖缺口，不宣称已查全。

仅在栏目网络重试后仍失败、404 / 410、空响应或无法提取正文时，尝试官方首页 `https://cet.neea.edu.cn/`，从其实际链接继续定位。登录跳转、401 / 403 或平台权限拒绝时停止，不通过换入口绕过。备用首页成功只能说明首页已取得，不能声称指定栏目或公告正文已取得；不得给 NEEA 地址套 GitHub 镜像。

## 查询次序

1. 从本轮上下文提取考试、级别 / 学段、考次和地区。报名学校、在读年级等只有影响资格且确实缺失时才询问，不收集身份证号、账户或密码。
2. 优先用环境网页工具读取 [official-sources.json](official-sources.json) 对应官方入口，在真实页面中定位适用考次的公告，再读正文。省级、考点或学校的报名窗口可能不同；明确自己的结论适用于哪一层，不用全国考试日推导学校报名日。
3. 工具缺失、访问失败或正文无法取得时，调用内置脚本。它仅抓公开网页，不登录、不报名，不猜文章 ID：

```text
python -I -S -X utf8 "<技能目录>/scripts/official_fetch.py" --exam cet
python -I -S -X utf8 "<技能目录>/scripts/official_fetch.py" --exam ntce --workers 4
```

脚本只取入口页，返回正文、实际链接、状态和截断信息；`--exam cet` 默认取上述考试动态栏目，成功时不额外抓首页；符合上述失败条件时才取备用首页。`fallback_used` / `fallback_recovered` 标明是否尝试及取得备用页面，`status: fallback_success` 不等于原栏目恢复；原失败记录仍在 `pages` / `failed_urls`。显式 `--url` 只取指定页面，不擅自改用首页。入口页成功不等于已取得考务公告。找到真实官方详情 URL 后，可用重复 `--url` 抓取详情，一次只取独立相关页面；脚本核对来源域名但不能替模型判断公告适用性。

4. 仅使用明确适用的公告。把公告发布日期、报名起止、考试日、成绩查询日分开，特别核对年份和已过期时间。用户说“今年、最近、下一次”，按当前北京时间与已核实公告解释，必要时写绝对日期。
5. 页面失效、反爬、登录页、无当期公告或地区不符，给出已核实部分和缺口。不把 URL 列表、搜索摘要或旧题库当作已核实的报考条件。

## 不可简化的区别

| 事项 | 核实要求 |
|---|---|
| 四级分数与六级报考 | 报告分数、学校报名条件和官方报考门槛分别核实；不把常见分数门槛一概称为官方合格线 |
| NCRE 级别、科目与获证 | 具体级别、版本、科目设置、成绩和获证条件分别核对；不把所有级别归纳为一科通过即可获证 |
| 教资报考 | 区分笔试、面试、资格认定，按地区、学段、学历和年级核对；不仅凭学校是职业技术大学推断资格 |
| 会计资格 | 看适用年度财政部门公告、地区要求和报名流程，不预测下一年日期、不把往年“无补报”写成永久规则 |

这些区别是查证要点，不代表本文件已核实某次资格。法规、政策和考试规则中的争议，引用官方原文并说明适用范围，不自行作保证。

## 交付

新闻按主题整合已读公告，说明查询时间、范围、发布日期与当前适用状态；报考查询先给“能确认什么 / 还缺什么”，再用表格列考次、事项、具体时间或条件、地区、官方原文。费用或资格未核实就写未核实。正文后依入口要求列“本次获取的 URL”，包含实际取得的列表和正文；发现但未读的链接不能列为已获取。失败地址及备用入口成功分别注明，最后给“快速预览：” Markdown 表格。若无网络能力且无适用公告，使用“日期待确认”的相对备考计划，不替用户猜考试日。
