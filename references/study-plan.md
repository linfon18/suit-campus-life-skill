# 可执行的复习计划

用户先问专业课程、实训或该考什么证时，分别先按 [培养方案行动导航](curriculum.md) 或 [可溯源证书咨询](certificates.md) 确认目标和依据，再用本参考安排学习负荷。不把方案列举的所有证书都塞进计划，不把学期课程计划称为个人实时课表。

用户已提供原始课表且要求结合排课安排时，先按 [课表综合建议](timetable-planning.md) 核对目标教学周、课程和已有承诺；再把本参考的复习任务放入用户确认可用的窗口。每日预算同时覆盖课程复习与考证训练，不各自使用一遍；没有预算时先给优先级与可选任务，不填满无排课时段。

从本轮提取考试科目、可用时间、已知日期和有证据的薄弱点，不要求学生重新填一份完整问卷。科目或时间预算缺失且会改变计划时集中问一次；暂时没有模考分或薄弱点，可以先做起始诊断。用户要求先给初稿时，明确假设每日 30 分钟等可调默认，不伪装成已知偏好。

## 日期与负荷

- 用户给了确切考试日就按该日倒排，默认不把考试当天安排为常规学习日。日期已过先核对，不继续生成过去的冲刺日程。
- 不知道考试日，只有用户要当期考务信息时才查官网；可先用第 1 至第 7 天给相对计划，标明尚未绑定考试日。
- 已明确是深圳信息职业技术大学专科大一学生且涉及四级报名时，结合 [本校报名条件补充](exam-info.md)：按用户提供的条件，最早大一下报考且大一上期末成绩须达到 80 分。大一上可以备考，但不安排为已具报名资格；尚未确认成绩、学期或当期校方通知时保留资格待核实，不凭“大一下”推定具体报名日。
- 计划每天合计用时不得超过当天预算，周末可单独指定，0 分钟是休息。漏学后不自动把所有欠账堆到第二天。
- 时长短时保留一个最薄弱考点的闭环，不照搬固定“三阶段”压缩模板。复测日期超过考试日时单列，不挤入考前一天。

日期、周末预算和分配可调用：

```text
python -I -S -X utf8 "<技能目录>/scripts/coach_tools.py" plan --start 2026-11-14 --days 7 --daily-minutes 30 --weekend-minutes 0
python -I -S -X utf8 "<技能目录>/scripts/coach_tools.py" review-dates --learned 2026-11-14 --intervals 1,3,7,14
```

`--days` 和 `--exam-date YYYY-MM-DD` 二选一，脚本只计算日历与分钟数，不提供考试日期、不替模型编造薄弱点。例子日期必须换成真实日期。

## 任务与调整

时间和基础允许时，可以按“补前置概念 → 专项迁移 → 综合限时与复盘”组织阶段；阶段长度由剩余天数、实际掌握证据和预算决定，不固定留两周冲刺。只剩一周或每天时间很短时，优先一个最影响结果的断点，不为完整阶段结构挤占复测时间。

CET 笔试计划涉及题型权重或限时时，按 [官方笔试结构摘要](exam-info.md) 区分四级与六级听力的题型和时长。分值占比作为优先级依据之一，结合实际薄弱点、剩余时间和训练证据分配学习时间，不把分值比例机械当成每日学习时间比例，也不把文字听力练习称为真实听力模考。

模型把可用时间填成“做哪一类题、检查哪一步、复测哪道题”，结合已分析错题编号，避免只写“复习英语”。每项说明题量或产物、时间和验收方式。资料没有章节编号就不编造具体教材页码。

输出可扫描的 Markdown 表格：日期 / 任务与题量 / 对应断点 / 用时 / 验收。用户只要一周就不输出一年。首次计划优先可执行，后续以实际完成记录调整。

复盘时区分样本量、独立答对和提示后答对；一题错不等于长期正确率不足，不按任意百分比直接加量。完成率低先查任务是否过重、资料是否齐全、时间是否可用，再减少任务保留闭环；重复同类错误时缩小前置概念、换一题对照验收。

用户要求“计划 + 一组练习”时，同轮给计划和相应起始练习，练习用时计入当天预算；未作答前隐藏答案。后续用户提交了完成情况，再按实际记录滚动调整，不假称会主动追踪每周进度。

不承诺跨会话记忆或自动提醒。需要可迁移记录时按 [session-state.md](session-state.md) 给出用户可审阅的短表，用户明确要导出时才创建文件。最后保留 URL 清单和快速预览。
