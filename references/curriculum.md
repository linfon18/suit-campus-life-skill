# 培养方案行动导航

将适用培养方案变成课程、实训和学期行动清单。只需培养方案即可开展，不要求先上传成绩单；没有成绩记录不能推算个人已修学分、挂科、毕业缺口或断言能毕业。用户自述完成情况可作条件分析，注明未经学籍系统核验。

## 适用版本与实时发现

官方入口：`https://www.suit-sz.edu.cn/xxgk1/jxzlxx.htm`。

先用环境网页 / HTTP 工具读栏目，按**入学年级、学历层次、专业及方向 / 班型**定位本次实际出现的详情，再从详情提取完整附件 href，解码 HTML 的 `&amp;` 并按原页解析相对链接。保留完整查询参数，不固化用户提供的 `afc`，不逆向、猜测或生成参数。该参数是否会过期尚不确定；实时从原页发现即可，不声称已证实反爬机制。

2026-11-14 实测该栏目列出了“2026级本科专业人才培养方案”和“2026级专科专业人才培养方案”，这只是核验记录，不保证永远只有两项。2026级指入学年级，不等于所有学生都用最新版；2025级学生不能自动改用2026级。相同年级有修订版时核对发布说明和适用范围，不能只凭页面顺序选定。

已有身份信息不要重问。需要个性化课程或毕业要求、但关键身份缺失时，只集中问一次必要项；可先列实际发现的方案范围。一个专业存在 Java / Python 方向、特色班、普通班或三二分段时不能合并推断，已知方向就直接定位，否则给候选再确认。没有用户年级时，最新方案只能作为标明年级的示例。

## 环境优先与预设保底

环境能可靠读附件和目标专业则直接处理，不额外运行脚本。网页读取无正文、只有 ZIP 链接、没有可用 FETCH、不能按专业解包，或需临时编写执行器时，调用包内预设脚本；不让模型通读源码或自行编造长命令。

```text
python -I -S -X utf8 "<技能目录>/scripts/curriculum.py" --level bachelor --cohort 2026 --major "软件工程技术" --find "职业技能" --find "毕业要求" --find "证书要求"
python -I -S -X utf8 "<技能目录>/scripts/curriculum.py" --level junior --cohort 2026 --major "Python" --find "毕业要求" --find "证书"
```

`bachelor` 为本科，`junior` 为专科；年级、专业和关键词换成本次真实条件。不传 `--major` / `--member` 时只列文件目录；`--member` 用返回的精确文件名消除歧义，不猜路径。语义筛选与结论由模型完成；`--find` 仅作原文定位，返回命中及前后两块，不代表已读完整毕业条款。否定性结论如“没有必考证书”必须读完整相关要求，不能因关键词无匹配得出。

脚本每次从栏目发现附件，仅用 HTTP Range 在内存读 ZIP 目录及选中的单个文件，不下载整个大包，不执行附件、不默认写盘。远端不支持分段、文件过大、校验变化或权限拒绝时说明实际缺口，不擅自下载百兆文件或切换身份。瞬时网络错误最多首次加两次重试；401 / 403、跳转、Range 不受支持不循环重试。空目录、没有对应年级或多专业匹配均为有效状态。

DOCX 保留段落、表格单元格、合并列和纵向合并标记；`unit: block` 的 `index` 从1开始，`--offset` 是从0开始的输出游标。`--find` 存在时游标指向筛选后的序列；后续保持原参数并使用返回的 `next_offset`，直到相关证据读取完整。再次联网分页须传原 `--document-sha256`，变化即停止混用。`truncated` / `oversized_unit` 表示还有未读正文，不能当完整条款。

优先在持久内存中处理本次文档，不预建目录、不传 `--export-dir`，也不因需要跨调用而自动导出。只有环境无法可靠保留文档或用户明确需要本地文件时，才准备已允许的任务目录，必要时在该区域创建子目录，再传 `--export-dir "<已允许任务目录>"`。该参数要求目录已经存在且可读写；脚本本身不自动创建，不存在时会在联网前明确提示先创建。目录权限拒绝时按平台权限处理，不换位置重试。仅保存目标文件、不覆盖其他文件、不写技能安装目录。环境已有文件阅读会话时复用本次文档，不反复下载。随后可只读处理同一文件：

```text
python -I -S -X utf8 "<技能目录>/scripts/curriculum.py" --level junior --read-file "<返回的export_file>" --document-sha256 "<返回的sha256>" --find "毕业要求" --offset 0
```

本地读取不联网，收尾不能新增已获取 URL；沿用本次真实取数记录及文件哈希。后续新咨询仍从栏目确认适用版本，不能因旧会话留有文件就称为实时。

DOCX 为标准库原生支持。PDF 优先环境文档阅读工具；环境已有 `pypdf` 时上述命令去掉 `-S` 可分页抽取（PDF每次最多6页）。没有解析器、扫描图或复杂图表无法确认时返回 `reader_required` / `ocr_needed`，只交付已核实部分。文本提取不等于版面核验；DOCX 图形、文本框可能重复或失序，附件未读的图片不猜内容。学期对应和学时学分须看表头与合并单元格，无法对应时说明未知。

## 从原文到行动

按用户问题读取相关章节，不为一个证书咨询抓所有专业。证据表至少包含身份适用范围、专业文件、原文条款 / 块号和结论：

| 用户需求 | 可交付内容 | 判断边界 |
|---|---|---|
| 专业学什么 | 课程群、培养目标、实训任务和职业面向 | 职业面向不是就业保证 |
| 本学期做什么 | 方案计划课程、准备顺序、练习产物和验收方式 | 培养方案不是个人实时课表，不推断上课地点或钟点 |
| 毕业有什么要求 | 明确的学分分类、实践环节和证书条款 | 不能判定个人达标；选修不得当全修 |
| 哪门课先学 | 原文明示的先修关系；另列模型建议顺序 | 学期先后、课程地图不自动等于强制先修 |
| 该考什么证 | 交给 [可溯源证书咨询](certificates.md) 接续官方检索 | “举例”“证书类课程”不等于必考 |

学分替代、证书二选一、等级至少达到某级、AND / OR 和适用例外按原文保留。总学分不能加上已经包含在其中的分项再算一遍；表格与正文冲突时并列来源，留待学校确认。建议的学习时间服从用户预算，无预算先给任务优先级，不编造每天空闲时间。

已有原始课表且要安排具体复习 / 实训窗口时，转 [课表综合建议](timetable-planning.md)，把适用方案中的课程要求与原始排课分别标注；方案学期安排不能覆盖用户课表，也不能凭课名认定具体章节已经讲到。

涉及本学期重修、学业清查、毕业材料或执行安排时，按 [新闻与教务通知](news.md) 查教务处公开通知，核对适用学期、年级和对象。培养方案解释长期要求，适用教务通知补充具体办理安排；未公开的校内附件或个人记录仍为未知，不能凭一则新通知宣称所有旧方案已失效。

交付按“已核实要求 → 这学期的行动 → 未知项”组织，正文就地附专业文件和原文章节 / 块号。末尾先列实际获取的完整 URL（Range注明分段获取），最后为“快速预览：” Markdown 表格，可用“事项 / 原文要求 / 行动 / 依据与待核实项”。不把目录读取成功写成全部方案已读。
