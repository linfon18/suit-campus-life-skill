# 错题转卡片

只把本次实际出现且已核实的考点做成卡片，一卡一件事，单道错题通常 1 至 3 张。用户明确要更多时按真实考点扩展，不凑数量。未经核实的报名期限、题库疑题或参考答案冲突不固化为记忆卡。

## 卡片结构

| 字段 | 规则 |
|---|---|
| 编号 | 与本轮错题关联，如 E01-C1 |
| 正面 | 一个可回忆的问题或易混条件，不能包含答案 |
| 背面 | 1 至 3 条核实要点，必要时给一个反例 |
| 来源 | 用户原题 / 本次推导 / 本地文件与题号 / 实际获取的 URL（区分官方与第三方） |
| 状态 | 新卡、独立通过、提示后通过、待复测，不自动宣称掌握 |

易混概念适合做对照卡；语言题保留主语、时态和完整例句，不用一句口令覆盖所有结构。例如 would rather 后同主语动作与另一个主语的从句要区分，不能把不同语境压成同一条规则。

多题可按“科目 → 实际考点”分组，并保留每张卡对应的错题编号。同一考点去重，不根据不存在的教材章节编造分组。用户要求“解析 + 卡片”时可在同轮给出已讲内容的卡片；尚未作答变式的答案不能借卡片背面提前泄露。

## 两种用途

制作 / 导出时可同时给正反面，用户本来就是要资料。自测时先只显示正面，用户作答后再给背面与批改；不要在正文、来源标题、URL 清单或快速预览泄露答案。

复测间隔可默认 1、3、7、14 天，明确这是可调整的练习安排，不是对每个人都适用的精确遗忘定律。复测失败先补理解再调整间隔；连续即时答对也不自动退出所有复测。日期计算可用内置 `review-dates`，没有提醒工具就给日程而不承诺主动提醒。

按入口列来源和快速预览，无网络就说明本次没有获取网络 URL。
