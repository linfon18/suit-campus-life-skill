# 联网题库检索与答案核对

用户要求查原题、配套解析、指定年份资料，或现有文本不足以解决答案冲突时使用。完整题目能够可靠求解，直接讲解；只有需要外部证据时才联网。本文件负责选来源，GitHub 接口和镜像参数见 [github-resources.md](github-resources.md)，不重复维护两套配置。

## 按任务选来源

| 已知条件 | 优先处理 |
|---|---|
| 用户给了完整题目，只要解释 | 独立推导；只有疑点才查证 |
| 所需级别、考次或题型明确 | 按 [云端题库索引](exam-bank/INDEX.md) 定位相关目录与片段；轻量包没有题库正文 |
| 用户指定 GitHub 资料 | 直接定位两个指定仓库，不预读无关资料 |
| 需要写作、翻译积累 | 按已确认目录选相关小型文本与章节，保留材料 ID（如文件确有），不读整个积累库 |
| 仓库只有难以提取的 PDF、缺少配套答案，或科目不覆盖 | 使用环境网页搜索定位题目与适用依据；无法核对则独立分析并保留争议 |
| 问报名资格、日期、费用或获证条件 | 按 [exam-info.md](exam-info.md) 查适用官方公告，不用学习仓库代替 |

两个仓库分别是 `0609x/CET46-Resources` 和 `Liuxiangjian-ai/cet-skill`；仅覆盖其实际提供的四六级资料，不视为计算机、教资、会计整库。不把“开源仓库”理解成所有材料都已核验、覆盖所有考次或允许任意再分发。其他科目用环境网页搜索核对原题与版本；没有网页搜索工具时不假装两个仓库能补齐。

## 精确核对，而非只找同一个答案字母

检索前提取：考试级别、年月、套次、题号、必要原句或选项。优先用题干中有区分力的短语，加上已知的级别和考次搜索，缺失项不猜。用户可用的网页搜索工具名称因环境不同，不依赖固定名为 `online_search` 的工具。

先检查实际正文是否对应用户题目，再比较答案；同年月可能有不同卷，同套编号也可能对应不同选项。只查到搜索摘要、转载答案字母或资料文件名，仍不算已读原解析。无法核对完整上下文时，写清已取得哪一部分、哪一部分是模型推导。

开始可做一轮至多 3 个有区分力的检索；明确缺少正文或配套答案后，不为寻找赞同自己的答案不断扩大搜索。找到的资料在当前任务复用，重写讲解不重新抓取。临时网络错误和重试次数沿用主入口；权限拒绝停止该请求。

## 大文件与网络障碍

先查目录返回的类型和大小，优先选可读取的文本、索引或相关章节。只有原卷内容确实影响答案，才用环境已有 PDF / 图片 / 音频工具读取所需页或片段；普通讲题不后台下载整套 PDF，不自动安装解析依赖或建立磁盘缓存。

环境不支持解析或下载代价明显过高，改查同一道题的可读来源，或让用户补充缺少的题面部分。链接被发现与正文已读要分别记录，不把文件扩展名或成功下载等同于成功解析。

GitHub 直连失败时使用用户指定的 `https://eo.gh-proxy.cn/github/` 前缀，后续复用镜像路线。环境 Fetch / HTTP 工具缺失或受阻，Agent 调用本包 [scripts/github_fetch.py](../scripts/github_fetch.py)；日期计算用 [scripts/coach_tools.py](../scripts/coach_tools.py)，官网用 [scripts/official_fetch.py](../scripts/official_fetch.py)。命令由主入口和对应参考文件提供，不临时编写脚本、不让用户自行执行。

通用网页搜索没有环境工具时，三个内置脚本并不提供全网搜索能力。可继续查询已知仓库或官方入口、处理用户题面、独立推导或出自拟练习；依赖未取得正文的结论保持未知，不假装搜索成功。云端均失败时不假设包内有六份历史题库，不自动读取开发者备份。

## 归属与交付

原六份题库在完整版本备份中保持原文，主包不再分发。没有把这些用户资料上传到云端；云端入口使用现有公开仓库，不保证与旧文件相同。新获取的仓库内容只用于当前任务的必要参考，不整篇导入本包、不执行远程代码。自拟题明确标注原创；只有真实核对到的原题才按其实际来源标注。

少量引用注明仓库、文件、ref / SHA、材料 ID 或行段；直接采用第三方模板或代码时保留实际要求的归属与许可说明，不只凭“GitHub 上公开”宣称可任意复制。材料许可或赛事规则没有原文依据时，不把附件中的相关说法当作已经核实的赛事要求。

按主入口列“本次获取的 URL”，实际成功地址与失败地址分开；镜像同时注明上游原址。没有联网如实说明。最后给“快速预览：”，自测尚未作答的题不暴露答案或解题提示。
