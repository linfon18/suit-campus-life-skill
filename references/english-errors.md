# 四六级：从答案回到证据

把当前阅读、译文或作文接入主入口的“核题、断点、变式、复测”流程。用户给了完整文本就直接处理；缺少原文、题目要求或需要历史材料核对，才按 [GitHub 按需检索](github-resources.md) 补充。仓库中的训练建议与评分模板是第三方参考，不视为官方评分标准，不复制整份提示词。

## 阅读：定位推断发生变化的一步

先独立找出支持选项的句子及必要上下文，再核对学生选项与理由。用一张小表比较“原文说了什么 / 选项多加或漏掉什么 / 结论”，只摘当前解题必要的短句。

| 可观察现象 | 要检查的变化 | 有区分力的变式 |
|---|---|---|
| 把 some 读成 all | 数量范围被扩大 | 保留内容，改变为 not every，检查能推出什么 |
| 选项沿用原词但结论不同 | 转折、否定、主客体或语境 | 保留词汇，改变主客体或一个否定条件 |
| 相关现象当成原因 | 原文是否提供因果证据 | 给出共同原因或明确因果方向的短段 |
| 错配代词或段落 | 指代、说话者与段落证据 | 保留主旨，改变指代对象，要求指出依据 |
| 陌生词导致误选 | 词义确实影响本题，还是推理另有错误 | 用易懂同义表达重写同一逻辑，区分词汇与推理 |

没有学生理由时，上述都只是待验证假设；不因一个字母给其贴“词汇差”标签。变式在内部检查后只呈现题面，避免标题或预览提前提示正确规则。

## 翻译：逐个信息单元核对

把原文分为必要信息及关系，检查译文是否保留主体、动作、对象、时态 / 时间、否定、数量、因果与修饰范围。先处理改变原意的问题，再处理语法、搭配和自然度；不把只是不同但成立的表达判错。

每次优先呈现 1 至 3 处影响最大的偏差：原片段、学生译法、问题证据、最小修正。用户要整段反馈时再提供完整参考译文，明确不是唯一“标准答案”。没有官方样卷评分依据时只作练习反馈；用户要估分可给说明口径与不确定性的范围，不报官方精确分。

验收不要只让学生抄修改句。给一个信息结构相同、内容不同的短句，先不放参考译文；学生回译后对照上轮断点检查。用户只要润色时直接交付润色，不强制补全考试流程。

## 写作：先修任务完成，再修句子

先核对题目要求与文章实际内容，依次检查观点与支持、段落衔接、语法和词语是否准确。没有题目要求时可以先改已知语句，但不能断言切题度、字数达标或完整估分。

指出文章中具体可定位的问题，例如某论据无法支持本段结论；不要泛评“逻辑不强”。先给最小修改与原因，用户要求整篇改写时再交付全文。避免把每篇都套成固定段数或堆砌高级词；保留成立的个人表达。

验收可以是重写一个薄弱句 / 段，或另写一句承担相同论证功能的句子。重写后逐处比较是否解决了上轮问题；不能从措辞更漂亮推断考试分数必然提高。

## 听力与题目版本

有音频且环境能播放 / 转写时，分别核对真实听到的信息、转写不确定处和题面。只有文字稿时明确是文本信息定位，不能算真实听力测验。音频文件名、同年月的“第几套”不足以证明与试卷一致；核对题目和选项后再用参考答案。

按主入口给本次实际 URL 和最后的快速预览；尚未作答题目不泄露答案。历史材料的命题风格只供参考，不据此预测必考题。
