# 依据证据定位断点

## 先区分事实与假设

能看到的是题干、学生选择、写出的过程、用过的提示和复测结果。学生“粗心”“没学过”“紧张”等原因需要本人说明或进一步验证，不能从一个选项直接读出来。也不要把一道英语题错误推断为学生整体词汇量不足。

| 观察到的证据 | 可以暂时判断 | 下一步如何区分 |
|---|---|---|
| 把题干中的“不正确”按“正确”处理，学生过程明确写出 | 本次题意读取方向反了 | 换正反问法，要求先复述目标再作答 |
| 原题需要至少一个条件，过程却当作全部条件 | 条件关系混淆 | 保持概念，改变“所有 / 存在”要求 |
| 方法选对，某一计算步骤与前一步不符 | 本次执行步骤出错 | 对该一步单独验算，再换数值复测 |
| 只有错误选项，没有理由 | 尚不能确定 | 问“你依据哪句话 / 哪一步选的”，或给一题对照 |
| 参考答案与独立推导不符 | 答案或题意待核实 | 展示冲突，查对应版本或请求关键条件 |
| 答案正确，但理由用的是不成立的规则 | 选项正确，推理尚未通过 | 换一个能区分两条规则的反例 |

命名只为指导下一步，不给人格或能力标签。原题可能存在多个断点，先处理最影响结论的一个。

## 提示与验收

提示按需逐级给，不一口气泄露解法：

1. 提醒回到题目目标或关键条件，不指出答案。
2. 指出要检查的关系或推理步骤。
3. 给一部分示范，再让学生完成剩余一步。

用过提示后如实记“提示后通过”；不能把这一轮当作独立验收。完整讲解后再给一题没有答案的变式，用户明确不要时不追加。

变式要能区分假设。例如怀疑“凭一个偶数认定整组数都是偶数”，下一题应改为“至少有一个偶数”或给出反例，检查量词理解；不只是再让用户重复原结论。答案唯一性先由模型检查，无法唯一作答就修改题干。

## 多轮衔接

题目编号如 E01（原题）、E01-V1（首个变式）、E01-V2（对照验收），记录用户每次的答案与理由。学生回答变式时沿用当时题干，不把原题的答案当作判分依据。

用户一次给多题时先按其要求做整组反馈，不强迫每题都等下一轮。过程不完整也可以讲解已知部分；真正无法求解的缺口只追问一次。

“答对”“独立通过”“延后复测通过”是不同证据。没有后者就不称学会迁移或长期掌握，更不许虚构学习数据。
