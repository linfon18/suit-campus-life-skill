# 🍚 深信大 · 食堂订餐及综合一语查

**想省几块钱，却要逐个食堂、逐家档口翻菜单？**

面向深圳信息职业技术大学学生，以食堂订餐一语查询与跨食堂比价为特色，兼顾校园生活与学习。问一句“15元吃什么”“哪里的鸡排饭最便宜”，把分散的信息整理成可比较、有来源的结果。

## ✨ 食堂查询，有哪些特点

### 一句话，把条件说清就能查

支持菜品、档口、菜单和平台营业状态查询；也能按预算、口味、明确忌口与食堂范围筛选。“换一家”“只看B食堂”等连续追问会承接本轮条件，无需记固定口令。

### 跨食堂比较，先看完整菜单

大范围比价一次采集本次平台返回的全部食堂分组、档口和完整菜单，独立菜单使用4至8路并发，再由模型理解商品类别、规格和需求，筛选排序。普通推荐按需要查询，不自动执行全校遍历。

### 价格与状态，一起讲清

分别列明菜价、盒费与可确认的规格差异，区分正餐和配菜、营业和暂停。注明采集时间、实际覆盖范围及未核实事项；不把部分结果写成全校绝对最低价。

### 结果附来源，也有快速预览

完成任务后列出实际获取的URL，最后以Markdown表格提炼重要信息。新一轮独立菜单查询默认重新获取；连续改筛选时按采集时效判断能否复用。

## 🧭 不只解决吃什么

| 模块 | 可以做什么 |
|---|---|
| 餐饮查询 | 查菜品、档口、菜单、规格与平台状态 |
| 约束选餐 | 按预算、偏好、食堂范围等条件筛选 |
| 食堂比价 | 比较同类餐品，分清菜价、盒费与规格 |
| 餐饮环境自检 | 按要求检查取数与执行能力，说明异常 |
| 校园周边一语查 | 查询本校周边餐饮、公园及生活服务 |
| 官网新闻活动与通知整合 | 提取消息、活动时间、对象与报名事项 |
| 培养方案行动导航 | 按年级、层次和专业查方案，梳理学习准备 |
| 实时可溯源证书咨询 | 查证报考条件、时间与官方依据，讨论选证 |

| 原始课表综合建议 | 分析课程分布、冲突、负荷和空闲窗口 |
| 课表转ICS | 对照原表核查后生成可导入兼容日历的文件 |

## 📦 下载与使用

1. 下载上方技能包，或克隆本仓库。
2. 按所用平台的自定义Skill导入流程安装，保留`SKILL.md`、`references/`及`scripts/`的相对结构。
3. 在对话中直接描述需求；分析课表或错题时，提供对应文件、截图或完整题目。

```bash
git clone https://github.com/linfon18/suit-campus-life-skill.git
```

该项目是由Agent加载的Skill，需要宿主环境提供模型、资料读取及相应联网或执行能力。中文技能名称、工具权限和导入方式由具体平台决定。

常规查询优先使用环境工具。能力缺失或取数遇阻时，保留11个Python脚本作为执行保底；脚本以Python标准库为主，PDF文字提取可按环境已安装的阅读工具或`pypdf`处理，不自动安装依赖。

## 使用口径

- 订餐能力用于下单前的查询与比较，下单及支付由用户在原平台完成。
- 菜单与平台状态可能变化，结果应保留采集时间及覆盖情况。
- 学校消息以实际读取的官网正文为依据，公开通知不等于个人教务数据。
- 培养方案与云端学习资料按需获取，不随包打入整套题库或培养方案压缩包。
- 课表先核对再转换。WakeUp等应用的导入格式需按对应说明核实，不预先承诺ICS可直接导入。
- 本项目不代表学校官方出品或背书。
